# R14 brief: one-key API endpoints and schemas (checked 2026-11-02)

Recommendation: use **fal.ai (FAL_KEY, `pip install fal-client`)** for every video model and Nano Banana 2.1 / GPT Image 2 / Recraft / FLUX 3. All fal pages read use `fal_client.subscribe("<id>", arguments={...}, with_logs=True)`, which is queue-based (submit, poll, result) under the hood; result JSON is `result["video"]["url"]` for video and `result["images"][i]["url"]` for images (R14-001..003). Auth is `Authorization: Key $FAL_KEY`. Page text was read through the fetch tool's summaries of fal `/llms.txt` pages, so the first run should still log the raw response.

## Traps that will break first-run code

- Field names differ per model: Wan uses `audio` and `start_image_url`; Kling uses `start_image_url`; PixVerse uses `generate_audio_switch`; Seedance, Veo, FLUX use `generate_audio`; MiniMax H3 uppercase `768P`; Gemini Omni on fal has no resolution field (R14 facts on each model).
- Duration type: integer for Wan, Kling, Grok, PixVerse, HeyGen, Gemini Omni, FLUX 3 Max; float for H3 Max; **strings** for Seedance (`"8"`) and Veo (`"8s"`).
- Defaults that cost money: Wan 3.0 defaults to 1080p; Kling 4.0 defaults to 1080p; Seedance 30 s at 1080p is about $35.
- Price conflicts (status conflict): Gemini Omni fal ~$0.125/s vs Google ~$0.10/s; Grok fal $0.14/s at 720p vs xAI $0.080/s; Nano Banana fal tokens about 17.6 percent above Google. Promos: H3 ends Nov 15, FLUX 3 Max ends Nov 7, HeyGen promo already expired.
- Google deleted its Veo 3.1 preview model ids on Oct 22, 2026; fal still serves `fal-ai/veo3.1` (page loaded, not test-called).
- BFL docs disagree on safety_tolerance range (0-4 vs 0-7); omit it.
